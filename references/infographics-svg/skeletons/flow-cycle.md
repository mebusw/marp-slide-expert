# flow-cycle — 流程骨架

> 有方向、有**闭合**或**收敛**的流动。四个变体：环形循环、漏斗收敛、桑基流量、闭环叠加。

## 何时用 / 何时不用

| ✅ 用 | ❌ 不用 |
|---|---|
| 循环过程：PDCA、飞轮、复盘迭代（环形） | 单向不闭合的直线流程（用 [linear-sequence](linear-sequence.md)） |
| 大量到少量：销售漏斗、转化率（漏斗） | 节点无数量差异的平铺流程 |
| 资源分配：钱从哪来、流向哪（桑基） | 只关心顺序不关心量（用箭头串） |
| 价值链、能量流、人口迁移 | 节点超过 12 个（桑基会糊成一团） |

### 硬规则

- **弧段画在节点圆之间，不要穿过节点。** 每段弧起止于两个节点圆的外缘（`R + 46` 和 `R - 46` 之间），不是整圆。
- **箭头方向统一顺时针**（或统一逆时针）。混用会读成两个循环。
- 圆心放一句总括的话（`.sm` 灰色），这是整张图的"所以呢"。
- 阶段数 3–6。7 个以上圆圈挤在一起，标签放不下。

### 变体：飞轮 Flywheel

环形 + 每段弧**加粗递增**（势能自我积累）。做法：把 `stroke-width` 从 2.5 逐段加到 6，并在外侧加同心弧表示累积。

### 变体：Focus / Spotlight 聚焦

圆心画高亮椭圆，节点向圆心发放射细线（`stroke-width="1"`，无箭头）。表达"资源集中一点"。

## 变体 B：漏斗 Funnel

**语义**：大量到少量，逐层转化。

### 形状：四条斜边必须在同一条直线上

漏斗最容易画错的地方是**每层各画各的**——层与层之间台阶错开，整体看起来像一摞歪掉的盘子，而不是一个漏斗。

**正确做法：先定一条贯穿全高的母线，所有层的斜边都落在它上面。**

```
母线    从 (120, 50) 到 (462, 356)          斜率 s = (462-120)/(356-50) = 1.118
左边界  x_left(y)  = 120 + 1.118*(y - 50)
右边界  x_right(y) = 900 - 1.118*(y - 50)
层高    h = 72      层间距 gap = 6      层 i 顶边 y_top = 50 + i*78
```

代进去，每层的两条斜边自动共线，整体是一个**完整的梯形**：

| 层 | y 区间 | 顶宽 | 底宽 | 左边界（上→下） |
|---|---|---|---|---|
| L1 | 50–122 | 780 | 619 | 120 → 200 |
| L2 | 128–200 | 606 | 445 | 207 → 288 |
| L3 | 206–278 | 431 | 270 | 294 → 375 |
| L4 | 284–356 | 257 | 96 | 382 → 462 |

### 宽度不等于量级——必须说明

为了四条边共线，层宽是**几何决定**的，不是数值比例。上例里底层宽度是顶层的 12%，而真实比例是 0.096%。

**这不是 bug，是漏斗的固有性质**——线性比例的漏斗会把底层压到看不见。所以规矩是：

> **漏斗的形状表达「方向和收敛」，数字表达「量级」。两者分工明确，图上要写清楚。**

底部那行 `.lbl` 注解不是可选装饰，是这张图的免责声明。**漏斗不能用来传达精确比例**——要精确比例就用 [桑基](#变体-c桑基-sankey-flow)，ribbon 宽度是严格正比于数值的。

### 硬规则

1. **四条斜边共线。** 先算母线，再逐层代入；不要一层层手画。
2. **每层都标数字。** 漏斗的唯一价值就是让人看到量级落差，没有数字的漏斗只是装饰。
3. **必须注明「层宽为示意形状」。** 否则读者会按线性去读那张图。
4. **最窄层留够字宽。** 底边 96px 时，`.tb` 19px 放得下 4 个中文字。放不下就把标签移到层外侧。
5. **底部注明总转化率**（`.lbl`），这是听众要找的最终答案。
6. **量级跨度过大时（>100:1）改用桑基。**

## 变体 C：桑基 Sankey Flow

**语义**：带**量级**的流动。源 → 中转 → 目标，流量用 ribbon 宽度编码。

### 硬规则

1. **Ribbon 宽度 = 数量。** 这是桑基的定义，不是修饰。每一带的宽度必须严格正比于其数值。
2. **守恒律（可验证）**：所有目标值之和**必须精确等于**源总量。写完逐个核对算术——源 85M，目标就必须加起来正好 85M，不多不少。**图上每个数字都要内部自洽。**
3. **Ribbon 颜色跟随源节点**，跨阶段保持一致（半透明 `opacity="0.45"`，让重叠可辨）。
4. **节点高度正比于通过该节点的总流量。**
5. **尽量减少交叉。** 调整节点上下顺序通常能消掉大部分交叉。

### 坐标公式（2 阶段）

```
阶段列 x   = 140 / 560 / 900        3 阶段时取前两个 + 一个
列宽 w     = 90
节点最小高 = 30
节点间距   = 20
viewBox    0 0 1020 520
```

**Ribbon 画法**（源节点上边 `y1`、宽 `h1` → 目标节点上边 `y2`、宽 `h2`）：

```
M 源右,y1
C 源右+40,y1  目标左-40,y2  目标左,y2
L 目标左,y2+h2
C 目标左-40,y2+h2  源右+40,y1+h1  源右,y1+h1
Z
```

```html
<path d="M230,120 C270,120 470,180 510,180 L510,300 C470,300 270,200 230,200 Z" fill="#4EBDBA" opacity="0.45"/>
```

节点标签放块**内侧**（右对齐到源节点左 / 左对齐到目标节点右），数值标在节点外侧。

### 变体

| 变体 | 结构 | 用在 |
|---|---|---|
| **Divergent 发散** | 1–2 个源 → 多个目标 | 预算分配、资源分发 |
| **Convergent 汇聚** | 多个源 → 1–2 个目标 | 收入归集、供给整合 |
| **Multi-stage 多阶段** | 3+ 列，既有分叉又有合流 | 供应链、价值链 |

容量：源 3–12、目标 3–12、阶段 2–4 为宜。

## 变体 D：闭环叠加件 Closed Loop

**不独立成图**，叠加在任何线性图底部，把「一次性流程」变成「持续演进」：

```html
<line x1="255" y1="392" x2="780" y2="392" stroke="#c0392b" stroke-width="2" stroke-dasharray="6 5" marker-end="url(#a1)"/>
<text x="510" y="422" class="lbl" text-anchor="middle">闭环：反馈 → 迭代 → 新价值</text>
```

虚线在关系图里默认表示**反馈 / 依赖 / 可选路径**，实线箭头表示**流程 / 因果**。

## 连线

| 关系 | 画法 |
|---|---|
| 环形阶段流转 | 弧线 `A` 命令 + 箭头，`stroke-width="2.5"` |
| 漏斗层间 | 形状本身的斜边就是边界，不需要额外箭头 |
| 桑基流量 | 闭合 ribbon path，半透明，宽度编码数值 |
| 反馈闭环 | 虚线 `stroke-dasharray="6 5"` + 双向 marker |

## 文字排布

- 环形节点标签：圆心垂直居中 `y = cy + 字号*0.4`（`.tb` 19px → `y = cy + 8`）
- 漏斗层标签：层内居中 `y = 层顶 + h/2 + 7`
- 桑基节点：名称 + 数值分两行（`.sm` + `.lbl`）
- 底部总括 `.lbl`
