# aged-academia

> 古籍与博物学图谱风格。羊皮纸底、乌贼墨、衬线字体、编号标本。**注意：已剥除纸纹与做旧效果**——平面矢量做不出真实纸张质感，硬加噪点只会显脏。

## Token

```css
--c-parchment: #F4E4BC;   /* 羊皮纸底 */
--c-parchment-2:#EBD9A8;  /* 深一档，做分区 */
--c-ink:       #704214;   /* 乌贼墨棕：主线条、主文字 */
--c-ink-2:     #5A3510;   /* 更深，压重 */
--c-faded:     #A8895C;   /* 淡墨：次级线条、注记 */
--c-rubric:    #9E2B25;   /* 朱红：标题、编号、重点标注 */
--c-text:      #3D2B14;
--c-muted:     #7A6444;
```

## 字阶

**衬线是识别特征**（中文用宋体/Songti SC，英文用 Georgia）。全大写不适用本风格。

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 标题 | 衬线粗体，**朱红色** |
| `.tb` | 图元编号 | 衬线中粗 + 朱红 |
| `.sm` | 拉丁名/术语 | 衬线**斜体** |
| `.lbl` | 边注 | 衬线小字 + 淡墨 |

## 形状语言

- **编号图元**：每个元素前加圈号或罗马数字（`①` 或 `1.` + 朱红）
- **细密排线（hatching）**：用 `stroke-dasharray="2 2"` 的平行线模拟，**不要用真纹理**
- **双线边框**：外粗内细的同心矩形，模拟古典图版
- **四角装饰线**：细直角折线，像书页角花
- 直线为主，圆角为 0 或 2

```html
<rect x="80" y="70" width="860" height="330" fill="none" stroke="#704214" stroke-width="2"/>
<rect x="90" y="80" width="840" height="310" fill="none" stroke="#A8895C" stroke-width="1"/>
<text x="110" y="120" class="t" fill="#9E2B25">形态与功能</text>
<text x="110" y="150" class="sm" fill="#3D2B14" font-style="italic">Morphologia et functio</text>
```

## 变体

| 变体 | 焦点 | 强调 |
|---|---|---|
| **Notebook 手稿** | 个人草图、发明 | 手写批注、页边注 |
| **Specimen 标本** | 分类学、编号图版 | 编号图元、拉丁标签、双线框 |

## 硬性规则

**Do**
- 羊皮纸底 + 乌贼墨棕是识别核心
- 衬线字族贯穿，中文用宋体
- 图元编号 + 拉丁标签（标本变体）
- 排线用虚线模拟，不要真纹理
- 留白宽松，模拟图版的天头地脚

**Don't**
- **真纸纹、噪点、霉斑**——矢量做出来是脏的
- 无衬线字体
- 饱和色、渐变、阴影
- 现代圆角
- 铁胆墨渍的随机色块

## 适合

学术溯源、历史脉络、文献综述、概念演化史、分类学式图解

## 配图建议

`hierarchy-tree` 关系树（分类谱系）、`linear-sequence` 阶梯（演化）、`structure-block`（标本图版）
