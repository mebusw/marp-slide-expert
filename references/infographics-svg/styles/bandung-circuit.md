# bandung-circuit

> 编辑插画风格。米纸底、双色克制、细线图标、**排版主导的层级**。读起来像一本杂志内页，而不是营销海报。

## Token

```css
--c-paper:     #F4EAD5;   /* 米纸底 —— 不可妥协，这是最强识别特征 */
--c-paper-2:   #EFE3C8;   /* 深一档米纸 */
--c-ink:       #1F5F66;   /* 深墨绿：标题、主块、结构强调 */
--c-ink-2:     #2A6E78;
--c-ochre:     #D6A946;   /* 芥黄：高亮块、选择性强调 */
--c-ochre-2:   #C99A3D;
--c-terracotta:#B86A55;   /* 陶土红：箭头、批注、告警（克制使用） */
--c-text:      #1F1F1F;
--c-muted:     #6B6358;
--c-panel:     #CDDDD8;   /* 淡墨绿：面板底 */
--c-panel-2:   #F2D896;   /* 淡芥黄：面板底 */
```

## 字阶

**单一字族贯穿全图**（推荐 Poppins；中文退到 PingFang SC）。层级靠**字号和字重**建立，不靠颜色饱和度——这是本风格与 deck 默认风格最大的差别。

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 标题 | SemiBold/Bold，字距略开 |
| `.tb` | 块标题 | Medium/Bold，**反白**（米纸色字压在实色条上） |
| `.sm` | 正文 | Regular/Medium |
| `.lbl` | 副说明 | Italic 或 Light |

## 形状语言

- **细线手绘感图标**：单线描边、无填充、线条略有起伏（不要 `<rect>` 这种绝对规整的图标，用 `path` 手写曲线）
- **扁平面板 + 内圆角 4–8px**——柔到像手工拼版，又不像现代 UI 那么油滑
- **块标题压在实色条上**（墨绿或芥黄底 + 米纸字）
- **箭头细而安静**：陶土红，`stroke-width="1.5"`，箭头点小
- 面板内项目符号用小实心圆点或破折号，绝不堆图标
- 边距宽松，构图呼吸但保持成组

```html
<rect x="60" y="80" width="280" height="180" rx="6" fill="#CDDDD8"/>
<rect x="60" y="80" width="280" height="40" rx="6" fill="#1F5F66"/>
<text x="200" y="107" class="tb" fill="#F4EAD5" text-anchor="middle">核心判断</text>
<circle cx="82" cy="146" r="3" fill="#1F5F66"/>
<text x="96" y="152" class="sm" fill="#1F1F1F">…</text>
```

## 硬性规则

**Do**
- 每张图锚定在米纸底上——这是识别度最高的单一特征
- 守住「墨绿 + 芥黄 + 米纸」，陶土红只做连接和强调
- 层级靠字重和面板位置，不靠颜色深浅堆叠
- 表面全平，只有纯色填充
- 箭头和连接线细而安静，不要喊话

**Don't**
- **白底**——米纸底不可妥协
- 深色或高饱和底——本风格是明亮的暖调，不是高对比
- 投影、渐变、发光、斜面、任何 3D
- 超过三个数据系列
- 大号统计数字（本风格信任版面，不信任 hero 数字）

## 适合

长文内页插图、专题、编辑部风格的内容、深度报道配图、学术社论式图解
