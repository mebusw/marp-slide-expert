# tricon-infographic

> 权威研究出版物风格。红色主导、白底、锐利、极简——锐利中带权威，像一份严肃的议题图解。

## Token

```css
--c-primary:   #C41E3A;   /* 主红：标题、数据标签、强调 */
--c-deep:      #8B1A2B;   /* 深绯：纵深、阴影块 */
--c-gold:      #D4A843;   /* 暖金：次级高亮（偶尔） */
--c-bg:        #FFFFFF;
--c-text:      #1A1A1A;
--c-text-2:    #4A4A4A;
--c-series:    #C41E3A #2A7B88 #B8860B #4A6FA5 #6B8E23;  /* 红色主导 */
```

## 字阶

| class | 用途 | 特征 |
|---|---|---|
| `.t` | 主标题、分区标题 | 几何无衬线粗体，紧凑 |
| `.tb` | 节点、编号 | 无衬线粗体 |
| `.sm` | 正文 | 无衬线常规 |
| `.lbl` | 图注、标签 | 无衬线小字 + 红色 |

## 形状语言

- **细红线做分区线**（`stroke="#C41E3A" stroke-width="1"`）
- **整幅红色面板**做强调段（红底白字）——本风格最强的视觉武器
- 直角，不用圆角
- 大留白，元素之间充分呼吸
- 极简装饰：让数据和文字自己说话

## 硬性规则

**Do**
- 红色是唯一主导强调色，同时传达紧迫感和权威感
- 保持宽边距和大留白——本风格传递的是「严肃研究」，不是「花哨信息图」
- 强调段用整幅红面板 + 白字

**Don't**
- 装饰插画、图标、剪贴画——这是出版物不是海报
- 渐变、投影、光泽
- 一张图超过 2–3 个颜色（核心是红 + 黑 + 白）
- 圆角、卡通元素、俏皮装饰——保持编辑部的庄重
- 章节编号（01/02）——信息图不是杂志排版

## 适合

研究报告、政策分析、议题图解、机构发布物、立场鲜明的观点图示

## 配图建议

`structure-block` 便当格（议题分区）、`linear-sequence` 阶梯（进程）、`network-hub`（利益格局）、`evidence` 图尔敏（论点与证据）
